### 5.1 AVOID list (explicit)

| # | Do not build | Why |
|---|---|---|
| A-1 | Hearts / punishment currency (lose a heart for a wrong answer / missed workout) | Punishing a body is not a lesson. Contradicts the no-guilt law and Lally. |
| A-2 | Global leaderboards (all users ranked together) | Demotivates 99% (Strava lesson). If competition, it must be small + similar + opt-in. |
| A-3 | XP for opening the app / tapping Koa / dressing the room | Rewards in-app grinding, not real behaviour (Finch rule). Every coin must trace to a real-world action. |
| A-4 | Live leaderboard / live classes now | Needs Realtime + APNs + moderation ASCND doesn't have; async presence (O-09) gets 80% of the value. |
| A-5 | AI as the author of loads, calorie targets, or medical interpretation | Hallucination + safety risk; deterministic engines own numbers (§3.2). |
| A-6 | Zombies, Run!-style audio narrative / story games | High production cost, niche, distracts from the training loop. |
| A-7 | 3D Koa now | No 3D asset, no pipeline, no code path (Koa audit §3.1); 2D state + performance fixes come first (mascot-system Option B). |
| A-8 | Demotion / league repair payments | Demotion feels like punishment; pay-to-repair monetises anxiety. |
