# `v13-set-redo/`: cảnh ghi set làm lại hoàn toàn (07/11/2026)

**Kiệt:** "lỗi nặng làm lại gấp, bỏ kiểu thiết kế cũ làm lại hoàn toàn" (xem `before-old-design.jpg`).

**Bỏ:**
- cận mặt làm đầu, tay, tạ bị cắt ở mép khung;
- vệt tốc độ, rung máy;
- Koa thu nhỏ bay vào vòng đồng hồ "1:30" để lại vũng sáng trống;
- số mẫu cứng.

**Mới (2,8 s), cùng ngôn ngữ cảnh xong buổi đã duyệt:** máy toàn thân cả cảnh, chỉ đẩy nhẹ 4 %.

| Thời điểm | Koa | Chữ, tiếng |
|---|---|---|
| 0 – 0,5 s | Rep cuối: nghiến răng đẩy tạ lên, run tay nhẹ | Hơi gió nhỏ |
| 0,56 s | Hạ tạ, nhắm mắt thở "phù" | "XONG SET!" + "Squat · set 1/2", hai nốt chuông, rung báo xong |
| 0,9 s | Tay kia giơ lên, mặt tự tin | Nốt gỗ |
| 1,15 – 2,8 s | Đứng thở đều, mặt vui | Ba thẻ: mức tạ, reps, giây nghỉ; tiếng tích nhỏ |

Chưa nối vào app: chờ Kiệt duyệt. Bản thật sẽ lấy số của set vừa ghi và giây nghỉ thật.
